<h1 align="center">月读</h1>
<p align="center">安静、轻巧的 Windows 桌面小说阅读器。整本连续滚动，透明桌面模式，自动记忆进度。</p>

## 功能

- **导入即读**：txt 自动识别 UTF-8 / GBK 编码，epub 一键转换；拖进窗口即可导入
- **连续滚动**：不按章翻页，整本书一个长页面；百万字大书秒开（分块渲染）
- **进度记忆**：按段落记住读到哪里，改字号、重开软件都不会跑位
- **章节定位**：自动识别“第X章”，输入数字直达，目录面板可点选、可筛选
- **自动滚动**：空格开关，十档速度，左右方向键调速
- **阅读排版**：字号、行距、纸张 / 纯白 / 护眼 / 夜间四种主题
- **桌面模式**：窗口透明只留文字浮在桌面上，背景浓淡可调，可置顶、毛玻璃、描边
- **老板键**：全局快捷键一键隐藏 / 恢复窗口，托盘图标常驻
- **联网搜书**（专业版）：兼容 [so-novel](https://github.com/freeok/so-novel) 的书源规则格式，自行导入规则文件后可搜索并整本下载到书架
- **窗口记忆**：大小、位置、模式全部记住

## 下载

到 [Releases](../../releases) 下载 `月读 Setup x.x.x.exe` 安装即可。Windows 10 / 11。

安装包未签名，首次运行若出现 SmartScreen 提示，点“更多信息 → 仍要运行”。

## 关于书源

月读**不内置任何书源**。搜书功能需要你自行导入 so-novel 格式的 json 规则文件（设置 → 管理书源）。规则抓取的内容来自第三方网站，请遵守当地法律与网站条款，仅用于个人学习研究。

## 快捷键

| 键 | 作用 |
|---|---|
| 空格 | 开始 / 停止自动滚动 |
| ← → | 调整滚动速度 |
| Ctrl + / Ctrl - | 字号 |
| 点击正文 | 隐藏 / 显示工具栏 |
| Ctrl+Alt+Q（可改） | 老板键：隐藏 / 恢复窗口 |

## 关于本仓库

本仓库是月读的**开源核心**（免费版）：书架、txt 导入、连续滚动阅读、进度记忆、章节定位、自动滚动、主题。
桌面模式、老板键、epub、联网搜书与授权模块为闭源部分，包含在 [Releases](../../releases) 的安装包中（新安装可试用 7 天）。

从源码运行核心版：

```bash
npm install
npm start          # 运行
npm run dist       # 打包，产物在 dist/
```
